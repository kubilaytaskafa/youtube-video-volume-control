# Changelog

All notable changes to this project are documented here.
Format based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), versioning follows [SemVer](https://semver.org/).

## [1.1.0] - 2026-10-20
### Added
- Keyboard shortcuts: `Ctrl+Shift+↑` / `Ctrl+Shift+↓` (`Command+Shift+↑/↓` on macOS) change volume by 1%.
- "Pin this tab as shortcut target" button, so shortcuts work from any tab.
- Toolbar badge showing the current volume.
- Credit line with author link in the popup.

## [1.0.0] - 2026-10-20
### Added
- Per-tab fine volume control (0–100%, 0.5% steps) for YouTube and YouTube Music.
- Preset buttons (1, 2, 3, 5, 10, 25, 50, 100%).
- Volume is re-applied automatically when YouTube changes it (e.g. next video).
